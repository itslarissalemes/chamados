# 🎫 Sistema de Chamados (ChamadosApp)

Aplicação web desenvolvida em **Java Spring Boot** para gestão e suporte de chamados de atendimento, com interface em **Thymeleaf** e **Bootstrap 5**, utilizando base de dados em memória **H2**.
